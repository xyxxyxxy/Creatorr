# UI (HTMX + daisyUI)

Index: [README.md](README.md). Agent contract: [`AGENTS.md`](../AGENTS.md).

**CSS.** Tailwind 4 + daisyUI 5. Source: [`internal/web/ui/src/input.css`](../internal/web/ui/src/input.css) (`@import "tailwindcss"` + `@plugin "daisyui"`) → committed [`internal/web/static/app.css`](../internal/web/static/app.css). `make css` also vendors **ECharts** and **Lucide**. After class or vendor bumps, run **`make css`**. Themes: all built-in daisyUI themes (`themes: all`); default follows OS (`light` / `dim`); override via navbar palette dropdown or sun/moon toggle (`localStorage` key `creatorr-theme`).

**Dev UI reload:** `CREATORR_WEB_DEV=1` (+ optional `CREATORR_WEB_DIR`, default `internal/web`) reloads templates/partials/static from disk each request. Compose mounts `./internal/web` at `/web`. CSS still needs `make css`.

**CSS priority (daisyUI first).** Fix UI with **stock daisyUI + Tailwind** in templates/partials, or daisy **theme tokens** via `@plugin "daisyui/theme"`. Prefer changing the HTML pattern over CSS.

When stock daisyUI is almost right but needs a small glue fix (overflow, stacking, clip): **prefer a minimal rule in `input.css`** over JS portals, third-party tooltip/popover libs, or other UI kits. Document each override with a one-line why. Do **not** add another CSS/UI library for chrome daisyUI already covers. If the fix is large or unclear → **stop and ask**.

**Current override:** `.modal` / `.modal-box` overflow in `input.css` so daisyUI tooltip tails are not clipped inside modals (scroll the overlay instead of the box). Desktop drawer: overlay pointer-events off + `drawer-content` above `drawer-side` so field tooltips are not covered by the sticky nav. Metadata ordered lists (genres/tags/actors): CSS counters on `[data-list-ord]` so row numbers track up/down without JS. List filter date/`datetime-local` join-item: transparent native control + min width so crush in the Filter join does not nest UA chrome.

**Icons.** [Lucide](https://lucide.dev) (ISC). Use `<i data-lucide="name" class="size-4"></i>`. `app.js` calls `lucide.createIcons()` on load and after HTMX swaps.

**Nav:** Series | Import | Tasks | History | Stats | Settings - brand **Creatorr** → Overview (`/`). Shell: sticky top navbar (bell dropdown **Unread alerts** + unread alert badge + theme) + drawer (`partials/nav.html`, `partials/head.html`). Tasks nav: primary badge = active task count; warning badge = soft-paused domain count. Task detail: `/task/{id}` (pending/running/finished). History (`/history`): page-header **From** / **To** (`from`/`to` UTC `datetime-local`, shared by both sections; empty = all time) then **Notifications** (filters `nevent`, page `npage`) then **Tasks** (filters `status`/`domain`/`kind`, page `page`). Notification list columns: icon (bell = info / red megaphone = alert, daisyUI tooltips `info`/`alert`), Event, When, Title. Rows → `/notification/{id}` (body, Channels `in-app` / `in-app, Apprise`, task link when set; opening marks alert read). Task rows → `/task/{id}`. Task history columns: Domain, Kind, When, Message (`error_code` / detail JSON on task detail only). Task **Detail** panel shows outcome JSON (e.g. scan `created_ids`) plus per-event video lists from `video_history` for that task (linked titles, same shape as discover). Task **Commands** panel (when any) shows shell-quoted yt-dlp/ffmpeg/ffprobe lines from `tasks.commands`, with a Pretty toggle like JSON sidecar view.

**Reuse / wrap first** - compose from `internal/web/templates/` and `internal/web/partials/`. When chrome would repeat, create or extend a shared partial. Any [daisyUI](https://daisyui.com/components/) component is fair game when it fits.

## Patterns

- **List / Add:** table for existing rows (`partials/list.html`); Add behind button/modal (no always-visible dashed form); Edit via per-row modal.
- **Notify channels (Settings → General):** fixed Creatorr in-app row (`creatorr://in-app`, all events, no edit/delete) + Apprise Add/Edit modal (`notify_channel_modal`); Apprise URL with link to [supported services](https://appriseit.com/services/); event checkboxes; HTMX Test. History + top-nav bell **Unread alerts** are the in-app channel; Apprise Test is not logged.
- **Tasks page:** alert above domain lanes explains soft Pause (blocks ClaimNext) vs interactive work: UI metadata prefetch and `stream_play` occupancy (still run while paused; domain must stay active; `stream_play` occupies the parallel slot). Host lanes include a History link with that domain filter pre-set. Nav Tasks shows a warning badge with the count of soft-paused domains (`#tasks-paused-badge`, from `GET /api/domains/paused`).
- **Domain defaults + overrides (Settings → Queue):** dedicated Domain defaults form (edits `domains` row `default`: cooldown, max download queue, max parallel tasks, rate/sleep/Flare/cookies); Domain overrides list (operator Add/Edit/Delete - limits/cookies/Flare only, **no** Active column). Shared override modal (diff vs default + per-field reset icon joined to the control; FlareSolverr select Default / On / Off - **On** disabled until Settings → General `flare_solverr_url` is set); also opened from Tasks lane **Edit** (host lanes only - **`system` has no Edit**). Download rate limit is a daisyUI join (number + `K/s`/`M/s`/`G/s`/Unlimited), not free-text. Hostname via datalist of source hosts. Missing host row = active + defaults. Inactive host (API) → actions disabled (tooltip → Settings → Queue). On `/tasks`: **`system` always shown first** (one-at-a-time maintenance / SponsorBlock cuts; no cooldown), then every known host (domains rows + source URL hostnames), even with zero tasks - no page-level empty state. Lane headers: paused badge, Pause/Resume, effective rate/sleep, cookie icon, cooldown countdown on host lanes.
- **Task progress:** running task indicators and task-row bars show a numeric bar/radial only when progress is strictly between 0 and 1. Nil, 0%, and 100% use the daisyUI spinner. Download tasks map yt-dlp percent into 0–1; **`sponsorblock_cut` re-encode** maps ffmpeg keep-segment (and filter-stitch when info cards force it) encode time into 0–1 via `-progress` (`out_time_*`; note `out_time_ms` is microseconds); **`media_verify`** null-decode maps ffmpeg decode time into 0–1 the same way (duration from ffprobe; unknown duration stays message-only spinner). Cards/remux/pack/copy-cut are message-only. Tasks list + task detail SSE-patch the status badge (same `status_badge` styles) when a task leaves pending.
- **Status badge:** `partials/status_badge.html` is icon-only Lucide (tooltip + `aria-label` for the name / longer tip). Colors align with `task_indicator`. Used on Tasks rows, task detail, History, and video-state chips in task detail payloads. SSE `statusBadgeEl` in `app.js` must stay in sync.
- **Roots / quality profiles:** table + Add modal; rows editable.
- **field_input / field_info:** shared fieldset + tip partials (`partials/field_input.html`, `partials/field_info.html`). Info tip always sits next to the legend label (not joined to the control). Optional `JoinPrefix` / `JoinSuffix` render non-editable daisyUI join labels around the text control (Episode format uses `Series/` + `.ext`). Notify channel Test is HTMX inside the channel modal. Single controls use plain `fieldset` ([daisyUI fieldset](https://daisyui.com/components/fieldset/)). Grouped sections use `fieldset bg-base-200 border border-base-300 rounded-box p-4` (docs “with background and border”); descriptions use `label` / `label whitespace-normal`. No custom fieldset CSS. Disabled inputs use a daisyUI tooltip (`DisabledTitle`, else `Hint`) on a wrapper; a hidden input keeps the current value in the form.
- **checkbox_field:** label text reflects control state - when `Disabled`, appends ` (disabled)` and uses `cursor-not-allowed` (not `cursor-pointer`). Mute only the label text (`opacity-60`), not the whole label - daisyUI already sets `.checkbox:disabled { opacity: .2 }`, and stacking both made the box nearly invisible. Disabled reason is a daisyUI tooltip on the control (`DisabledTitle`, else `Hint`) - no Hint paragraph under a disabled checkbox.
- **Preset fill:** `partials/preset_fill.html` - cron text field with `@…` datalist. Free-form cron still allowed. Empty Scan = never (manual OK).
- **Empty values:** list/table cells use `partials/empty_value.html` - ASCII `-` (`empty_value`) or custom labels (`muted` for never/none/default) via `opacity-60`. Detail page key/value rows use `partials/detail_row.html`: empty greys the **value cell only** (`opacity-60` on `td`) and shows `none` / `never` / … (not `-`); keys stay full opacity.
- **List filters:** `partials/list_filters.html` - daisyUI `join` (optional search `q`, optional date as [label-for-date-input](https://daisyui.com/components/label/#label-for-date-input) join-item with `shrink-0 min-w-60`, optional selects, optional hidden fields; no leading Filter label). Select/date/`datetime-local` change submits immediately; search submits on blur (`js-list-filters` in `app.js`). Used by series videos (`status` then `source`, always shown), `/series` (`root`/`quality`/`monitored`), History notification section (`nevent`), and History task section (`status`/`domain`/`kind`; no search). History page header uses `history_range_filters` (`from`/`to` UTC `datetime-local` join; full page GET). Hide a select when fewer than 2 options (series list root only; History keeps domain/kind even when empty). HTMX into `#series-videos-live` / `#series-list-live` / `#history-live` / `#notification-history-live` when `LiveTarget` set. Thin wrapper: `video_list_filters.html`. Series video rows show media type in the meta line (`-` when empty); no media-type filter control.
- **Filter bar:** `partials/filter_bar.html` (checkbox chips); hide when fewer than 2 options; empty selection = show all. Prefer **List filters** for new list pages.
- **List row shell:** `partials/list_row_shell.html` - media | title+kind+warn+task | line2 | optional `series_progress` | actions (`monitor_toggle`). Series rows: `series_list_row.html` (circular poster). Video rows keep custom meta/`time` in `video_list_row.html`.
- **Series list:** `/series` is a filtered media list (`series_list_live` + page size 20). Filters: name (`q`), root (hidden when only one root), quality, monitored. Row line 2 omits root when only one exists. Monitor icon left of title always shows monitored/unmonitored (`series_monitor_indicator`). Health/busy badge on poster top-left only when needed (`series_status_indicator`; priority: source error → download error → verify → source scan error → full-scan incomplete with no schedule → running task → pending task). Monitor toggle is an icon button (works with zero sources); always HTMX-refreshes `#series-list-live`.
- **Source status:** one **Status** column on series Sources (icon + short label). Kind icon on the URL row (`list-video` channel/playlist / `list-minus` when new-as-ignored / `film` single video); no separate badge. Status priority: running → pending → scan error → stalled/incomplete → indexed / no schedule. Incomplete with a tip schedule uses warning `calendar-x-2` (schedule will continue; no series escalate); tip is `Full scan incomplete` then next-scan line. Incomplete with no schedule uses red `calendar-off` and escalates to series status; tip is `Full scan incomplete` then `No scan scheduled`. Both incomplete and indexed-feed tips insert `Regexp filters apply` before the next-scan / no-schedule line when title include and/or exclude is set. Indexed singles show green `calendar-check-2` + `complete`; tip is only `Scanned … ago`. Scheduled feeds show last-scan summary as the label; tooltip via `tooltip-content`: optional `Scanned until YYYY-MM-DD`, optional `Regexp filters apply`, then `Next scan in …` (missed slots → next cron after now). Live OOB via `/series/{id}/task-indicators` swaps the Status cell. Source detail keeps status in Source settings / History only (not the page subtitle).
- **Scroll keep:** full-page list nav (pager links, filter GET) uses class `js-keep-scroll` - `app.js` saves/restores `scrollY` for same pathname. Prefer HTMX live swap when a panel already has a target (`PageInfo.LiveTarget` / filter `LiveTarget` → `#series-videos-live` / `#series-list-live` / `#history-live`); that path restores via `htmx:beforeRequest` / `afterSwap` instead.
- **Video list notes:** Pager only below the list. No date fields in the join (optional `from`/`to` query still parsed).
- **Tooltips:** daisyUI `tooltip` + `data-tip` only - never native `title` for tips. Prefer `tooltip` on `btn`/`badge`/`span`; wrap Lucide icons; do not put `tooltip` on `flex`/`td` hosts (breaks layout - wrap a child instead). Keep `aria-label` where it already exists. `list_table` omits `overflow-x-auto` so tip tails are not clipped by the bordered wrap. **Labeled text buttons:** no tooltip when `data-tip` would only repeat the visible label (icon-only / disabled-reason tips still OK).
- **Video detail files:** one Files table (media first: `video` then `.strm`, then stem-matched companions beside the media: NFO / info.json / thumb / subs / `.sponsorblock.json` / other). Help mentions SponsorBlock plan. File names open `/series/{id}/videos/{vid}/files/{fid}` when the path is registered in `files` (text/`<pre>`, thumbs as image, JSON Pretty toggle, packed video = plain `<video controls>` from `…/raw` - browser codec limits apply). Disk-only orphans list without a view link. Raw at `…/raw` (`?download=1` for Save As).
- **Stream cache (video detail):** for `streamable` pipe videos, a **Stream cache** row replaces Beginning cached yes/no: daisyUI progress + `% · cached / duration` from max(beginning, playback cache). CDN-direct omits the bar.
- **Series detail files:** Files table below videos for series-folder metadata (`tvshow.nfo`, poster/banner/fanart/clearlogo when present). Names open `/series/{id}/files/{role}` (text or image preview); raw at `…/raw`.
- **Metadata suggestion pool:** series + video Metadata modals share one library-wide datalist per field name (studio, genres, tags, country, mpaa, actor name, actor role) via `ListMetaSuggestions` - values from both tables. Studio / country / mpaa use `metadata_suggest_row` ([label-for-input](https://daisyui.com/components/label/#label-for-input) + datalist). Genres + tags share `metadata_string_list_editor`; actors use bordered `fieldset` (locked rows name/role 50/50; draft is one daisyUI `join` of Name/Role label-for-input + plus). Added items: 1-based order index + Lucide chevron reorder + minus remove. Suggestions via native `<datalist>` only. See [`download-and-library.md`](download-and-library.md).
- **String-list unordered:** `metadata_string_list_editor` with `NoReorder` / `data-string-list-unordered` renders daisyUI **badge** chips (flex-wrap left-to-right, Lucide `x` remove) plus draft input below; new values append (no client re-sort; server may still normalize on save). Used for series **Media types** auto-ignore (`auto_ignore_media_types` on Edit series / add-series); suggestions = YouTube seed ∪ customs from all series auto-ignore lists (never `unknown`). Also Library **Subtitle languages** (`subtitle_langs`; suggestions = `all` first then common tags).
- **Source filter section:** feed add/edit (and add-series source step) groups cutoff + title include/exclude under a **Filter** heading (`partials/source_filter_fields.html`) - these **exclude from index** (exclude wins over include when both match). Series **Media types** auto-ignore (Edit series / add-series series step) index first, then mark ignored when metadata appears (esp. at download).
- **Series settings fields:** Add series (series step) and Edit series share `partials/series_settings_fields.html` - Delivery method first, then title, root, quality profile, media-types auto-ignore.
- **Metadata fetch bar:** series + video modals use one daisyUI `join` (`partials/metadata_fetch_url.html`): URL input + Fetch. Video: default `source_url`. Not a raw NFO/sidecar editor; Files table stays view-only. Video detail header **Refresh sidecars** enqueues `refresh_sidecars` (thumb / subs / NFO rewrite; never `info.json`).
- **Modals:** daisyUI checkbox + `.modal-box`; backdrop is a non-interactive `<div class="modal-backdrop">` (no outside-click dismiss). Close only via Cancel / explicit action labels on the toggle. **Cancel** runs `form.reset()` and restores metadata art-slot previews (`data-art-preview` → `data-orig-src`, revoke object URLs, clear `clear_{role}`); closing the toggle without Cancel keeps form state. Series metadata art: Lucide `x` on daisyUI `indicator` sets hidden `clear_{role}=1` and hides the whole preview wrap (never the indicator-item alone - that jumps the X); new file upload clears the flag and shows preview again.
- Prefer daisyUI + shared partials; no second styling system.
- **Flash:** `ok`/`err` query → `partials/flash_toast.html` (daisyUI toast, auto-dismiss + URL strip in `app.js`). Success `alert-success`, warn `alert-warning`, err `alert-error`. Not inline page banners.
