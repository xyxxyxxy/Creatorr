# UI (HTMX + daisyUI)

Index: [README.md](README.md). Agent contract: [`AGENTS.md`](../AGENTS.md).

**CSS.** Tailwind 4 + daisyUI 5. Source: [`internal/web/ui/src/input.css`](../internal/web/ui/src/input.css) (`@import "tailwindcss"` + `@plugin "daisyui"`) → committed [`internal/web/static/app.css`](../internal/web/static/app.css). `make css` also vendors **ECharts** and **Lucide**. After class or vendor bumps, run **`make css`**. Themes: curated daisyUI set on Settings → General **Appearance** (Dark / Light / Special); default follows OS (`emerald` / `dark`); override stored in `localStorage` key `creatorr-theme` (this browser only).

**Dev UI reload:** `CREATORR_WEB_DEV=1` (+ optional `CREATORR_WEB_DIR`, default `internal/web`) reloads templates/partials/static from disk each request. Compose mounts `./internal/web` at `/web`. CSS still needs `make css`.

**CSS priority (daisyUI first).** Fix UI with **stock daisyUI + Tailwind** in templates/partials, or daisy **theme tokens** via `@plugin "daisyui/theme"`. Prefer changing the HTML pattern over CSS.

When stock daisyUI is almost right but needs a small glue fix (overflow, stacking, clip): **prefer a minimal rule in `input.css`** over JS portals, third-party tooltip/popover libs, or other UI kits. Document each override with a one-line why. Do **not** add another CSS/UI library for chrome daisyUI already covers. If the fix is large or unclear → **stop and ask**.

**Current override:** `.modal` / `.modal-box` overflow in `input.css` so daisyUI tooltip tails are not clipped inside modals (scroll the overlay instead of the box). Desktop drawer: overlay pointer-events off + `drawer-content` above `drawer-side` so field tooltips are not covered by the sticky nav. Import list/summary: raise `#import-list` / `#import-summary-tree` tooltip hosts on hover so daisyUI tip bubbles are not covered by sibling filename/Match chrome. Metadata ordered lists (genres/tags/actors): CSS counters on `[data-list-ord]` so row numbers track up/down without JS. List filter date/`datetime-local` join-item: transparent native control + min width so crush in the Filter join does not nest UA chrome. Form `validator`: neutralize daisyUI `:user-valid` success green so only invalid fields get error color (`aria-invalid` / `:user-invalid`); neutralize skips hosts with `aria-invalid` so client errors still paint red on empty optional fields. `.tooltip-nowrap`: keep long `data-tip` on one line in monospace (quality profile format selectors; stock daisyUI wraps at 20rem).

**Icons.** [Lucide](https://lucide.dev) (ISC). Use `<i data-lucide="name" class="size-4"></i>`. `app.js` calls `lucide.createIcons()` on load and after HTMX swaps.

**Nav:** Series | Import | Tasks | History | Stats | Settings - brand **Creatorr** → Overview (`/`). Overview shows library stats plus a **Recent additions** video list (newest `downloaded` across all series by `acquired_at`, same row chrome as series Videos, no delivery/want/ignore actions; series title in the meta line). Shell: sticky top navbar (bell dropdown **Notifications** daisyUI `menu` of latest 4 in-app notifications with unread rows `menu-active`, **Mark all as read**, and **View all**; unread alert/warning badge) + drawer (`partials/nav.html`, `partials/head.html`). Main content column is `max-w-5xl` (~1024px) and centered. Series nav: error badge = count of series with video error statuses or a source scan_error (`GET /series/error-count.json`; hides when 0; refreshed with Tasks badges on SSE + 15s poll). Tasks nav: primary badge = active task count excluding soft-paused domains; warning badge = soft-paused domain count. Task detail: `/task/{id}` (pending/running/finished; HTMX log Refresh / load swap scrolls the log pane to the bottom). History (`/history`): page-header **From** / **To** (`from`/`to` UTC `datetime-local`, shared by both sections; empty = all time) then **Notifications** (opening History marks all unread alerts/warnings read; filters `nlevel` type, page `npage`) then **Tasks** (filters `domain`/`kind`/`status`, page `page`). Notification list columns: icon (bell = info / amber `siren` = warning / red megaphone = alert, daisyUI tooltips), Event, When, Title. Rows → `/notification/{id}` (body, Channels `in-app` / `in-app, Apprise`, task link when set; opening marks unread alert/warning read). Task rows → `/task/{id}`. Task history columns: Domain, Kind, When, Message (`error_code` / detail JSON on task detail only). Task **Detail** panel shows outcome JSON (e.g. scan `created_ids`) plus per-event video lists from `video_history` for that task (linked titles, same shape as discover). Task **Commands** panel (when any) shows shell-quoted yt-dlp/ffmpeg/ffprobe lines from `tasks.commands`, with a Pretty toggle like JSON sidecar view.

**Reuse / wrap first** - compose from `internal/web/templates/` and `internal/web/partials/`. When chrome would repeat, create or extend a shared partial. Any [daisyUI](https://daisyui.com/components/) component is fair game when it fits.

## Patterns

- **Import page:** when no series exist, Scan/import UI is hidden; page shows a message that a series must be created first plus an **Add series** button that opens the shared add-series modal (on `'Import'`, `'Mark new videos as ignored'` is checked and disabled with a tooltip). Page help recommends creating the series and sources with `'Mark new videos as ignored'` first so a video index is available to match the files automatically (when series exist: File matching section header (list_header) with help list above the series-first info alert under the page header; incomplete `'Full scan'` note above the file list is warning). When series exist: on load, runs one Scan for the selected folder (default inbox). While any source still has an incomplete `'Full scan'` (`full_scan_done=0`), a warning alert above the file list notes that not all videos may be indexed yet for auto-match (wording is about incomplete index, not a running scan task; live-hides via SSE when scans finish). After Scan, candidates render as a vertical `<ul>` of bordered list items (not a table) - one item per stem group (media + sidecars; group key casefolds and strips `[id]` so NFO/thumb without matching brackets still merge), sidecar-only Attach groups, or non-importable other files. Each importable row: file stack + match note on the left (auto-match label until Match changes the target; then `Matched to Series / Title`, `Attach to …`, or `Create new video: Title on Series`); right side icon actions vertically centered - status `check` (matched) / `circle-dashed` (not matched) / `x` (not importable) at `size-6`, then `gap-3`, then Match action (`link` Match when unmatched / `unlink` Unmatch when matched; `btn-primary` unmatched / `btn-soft btn-primary` matched; disabled soft `link` on non-importable rows). Unmatch clears the pick so Match can be opened again. No inline series/video summary text. File rows show primary basename with role icon; same-stem sidecars as `+ N sidecars` then role icons (no tooltips on role icons). Auto-match note omits the remote ID value (`Matched by remote ID to Series / Title`). Status line: file/item counts on the left; unique matched videos and series count on the right. Toolbar: one row with **Auto-match** (re-applies scan suggestions to every importable item; disabled after Scan/library switch or Auto-match until a Match/Unmatch/bulk series pick or **Reset matches**), **Reset matches** (clears series/video picks on every importable item), **Pick series for all unmatched** (opens Match series-only; picking a series applies it to every importable item that still has no series) as a daisyUI `join`, then **Show only unmatched**, and **Import** right (count of ready items; [aura-rainbow](https://daisyui.com/components/aura/#aura-rainbow) when every importable item is matched, ignoring listed-only). Scan folder select auto-scans on change (and once on page load); joined **Rescan** re-scans the same folder for new files without clearing current matches. Folder change, **Rescan**, and **Auto-match** show a flash toast with how many scan auto matches were found (`N auto matches found.` / `No auto matches found.`; initial page-load scan stays quiet). Match modal: fixed `h-[90vh]` (lists fill leftover height); series-only Pick series uses `max-w-2xl` (half of two-pane `max-w-4xl`); name search, series list (poster) and video list (thumb) - less detail than the main library lists; selecting a series locks that list to one row with X to change; selecting a video (or finishing Add video index) applies immediately and closes Match; series list always offers **Create new series** (opens shared Add series modal with the same **From channel / playlist URL** / **Create manually** choice as Overview; on `'Import'`, `'Mark new videos as ignored'` is checked and disabled with a tooltip; on success stays on `'Import'`, locks that series in Match); **Create new video** is always at the top of the media Match video list (pick a series first if none locked) and opens the shared **Add video** modal (`partials/add_video_modal.html`; reusable markup, Import-only wiring for now - not on series Videos yet). Add video: Fetch URL is primary (interactive `prefetch_add_video` → draft under `cache/add-video/{token}/`; then `POST /api/series/{id}/videos` with `draft_token`); manual fallback is Title + Upload date only with read-only Remote ID from file hints or generated on create; new row status is **`ignored`**. On success Match applies the real `video_id` and closes. Series-only scan suggestions fill the series and leave the video empty (operator picks or creates a video in `'Match'`; scan never auto-CREATE). Search disabled while a prior video pick is locked for change; **Allow matching existing media** only shown for media match (hidden for sidecar attach); when off, media Match omits packed media; sidecar Attach hides Create new series / Create new video and only lists videos that already have packed library media; **Allow matching existing media** lives in that modal (off by default: omits packed media; when on, includes them with `· has media` and import deletes that media then installs the new file). A given indexed video can be matched to at most one media import item (always hidden from other Match lists once claimed; duplicates from scan auto-suggest are scrubbed). **Import** opens a read-only summary tree (series → episode → files with role icons; NFO rows note used for metadata and re-generated on import); path on hover); summary warns when any item will replace existing media; **Import now** (secondary) queues without verify; **Import now and verify media** (primary, rightmost) queues with `verify=true`. **File matching** section header with rules list (above the series-first info alert) covers ID / title / series / sidecar basename. Scan folder sits below. Orphan `info.json` is listed only (provenance; packs with media bind/import, never attach alone). `.nfo` / orphan thumb are metadata-or-art only with a same-basename sibling video (media import group or beside packed library media); alone they are listed only. Orphan/sibling apply updates editable metadata then regenerates the library episode NFO from DB (source XML not kept).

- **Tooltips:** daisyUI `tooltip` + `data-tip` only - never native `title` for tips. Prefer `tooltip` on `btn`/`badge`/`span`; wrap Lucide icons; do not put `tooltip` on `flex`/`td` hosts (breaks layout - wrap a child instead). Keep `aria-label` where it already exists. **Mute-inner rule (tip-safe):** never put `opacity-*` on the `.tooltip` host **or any ancestor** of `.tooltip` (fieldset, join wrap, label, …) - CSS opacity composites the tip `::before`/`::after` bubble and children cannot undo it. Mute only leaves (icon, label text, hint, range readout). Form controls: prefer daisyUI `:disabled` styling - do not stack `opacity-*` on the control. Canonical copy-paste: `partials/checkbox_field.html` (tip wraps control; `opacity-60` on `label-text` only), `partials/monitor_toggle.html` / series source kind icons (tip host + inner icon `opacity-*`), `partials/field_input.html` disabled path (tip wraps control; mute legend label / hint / readout, not the fieldset or tip host). Prefer `text-base-content/50` over host `opacity-*` when muting icon color on a tip host (`status_badge`). JS that disables fields must follow the same rule (do not `classList.toggle("opacity-*")` on a fieldset that may contain tips). `list_table` omits `overflow-x-auto` so tip tails are not clipped by the bordered wrap. **Labeled text buttons:** no tooltip when `data-tip` would only repeat the visible label (icon-only / disabled-reason tips still OK).

- **Modals:** daisyUI checkbox + `.modal-box`; backdrop is a non-interactive `<div class="modal-backdrop">` (no outside-click dismiss). Close only via Cancel / explicit action labels on the toggle. Modal **Cancel** / **Keep** dismiss controls use plain `btn` (not `btn-ghost`; see notify-channel modal). **Cancel** runs `form.reset()` and restores metadata art-slot previews (`data-art-preview` → `data-orig-src`, revoke object URLs, clear `clear_{role}`); closing the toggle without Cancel keeps form state. Series metadata art and video thumbnail: Lucide `x` on daisyUI `indicator` sets hidden `clear_{role}=1` and hides the whole preview wrap (never the indicator-item alone - that jumps the X); new file upload clears the flag and shows preview again.
