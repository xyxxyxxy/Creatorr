# UI (HTMX + daisyUI)

Index: [README.md](README.md). Agent contract: [`AGENTS.md`](../AGENTS.md).

**CSS.** Tailwind 4 + daisyUI 5. Source: [`internal/web/ui/src/input.css`](../internal/web/ui/src/input.css) → committed [`internal/web/static/app.css`](../internal/web/static/app.css). `make css` also vendors ECharts and Lucide. After class or vendor bumps, run `make css`. Themes: curated daisyUI set on Settings → General **Appearance** (Dark / Light / Special); default follows OS (`emerald` / `dark`); override is this browser only (`localStorage` key `creatorr-theme`).

**Dev UI reload:** `CREATORR_WEB_DEV=1` (optional `CREATORR_WEB_DIR`, default `internal/web`) reloads templates and static files each request. Compose mounts `./internal/web` at `/web`. CSS still needs `make css`.

**Document title:** the browser tab is always `Creatorr`. In-page headers still use the page title.

**daisyUI first.** Stock daisyUI + Tailwind in markup, or daisy theme tokens. Prefer a different HTML pattern over custom CSS. A small glue fix (overflow, stacking, clip) belongs in `input.css` with a one-line why. Do not add another UI kit. A large or unclear fix: stop and ask.

Glue already in `input.css` (the why, not the selectors):

- Modal tips must paint outside the box, so the overlay scrolls and the box does not clip. Modals sit above the shell navbar. Tall previews without tips scroll inside the box.
- The bell menu and flash toasts sit above open modals. Toasts sit below the navbar so they do not cover the bell.
- Import list and summary tips rise above the next row on hover.
- Genre, tag, and actor rows number themselves so reorder does not need JS.
- Filter date fields stay transparent and wide enough that the browser control does not look nested.
- Validators show error only. A valid field stays neutral, including after Save on an empty optional field.
- Long format-selector tips stay one monospace line.
- A bulk-selected list row is square so the selection fill covers it.
- A radio join highlights the checked choice.
- The app column is at least the `md` width so page padding does not jump; narrower viewports scroll sideways.

**Icons.** [Lucide](https://lucide.dev). Recreate icons on load and after HTMX swaps.

**Nav.** Series, Tasks, Import, History, Stats, Settings. Brand **Creatorr** goes to Overview. Overview shows library stats, then **Running tasks** while any task is running (all domains, kind links to the task, no Cancel), then **Recent additions** (newest downloaded videos, same row as series Videos, no row actions, series title in the meta line).

Shell is one centered column. Below the `md` width the column scrolls sideways instead of reflowing. Small screens get a hamburger; wide screens get a horizontal menu. The end of the bar is the bell (latest four in-app notifications, unread rows marked, **Mark all as read**, **View all**, badge for unread alerts and warnings) and the user menu (name + **Log out**). Footer: version, `docker` or `binary`, short commit (links to GitHub when it is a sha), and the repo link. Settings is a submenu (General, Library, Connect, Queue / Domains, Scheduler, Maintenance) and does not stay open after navigation. Series shows an error count when any series has a video error or a source scan error (hides at zero). Tasks shows an active-task count (excluding soft-paused domains) and a warning count of soft-paused domains. Task detail is `/task/{id}`: **Stages** beside **Details** (outcome keys and per-video lists), **Commands** full width when present, **Logs** under that. The log pane scrolls to the bottom on load and on Refresh. Stages always include **enqueued**; a single-video task uses that video's history; otherwise **started** comes from `started_at`. Finished tasks end with **done**, **failed**, or **cancelled**. Duration is the gap from the previous row (largest unit, omit a second or less). History has a shared **From** / **To** range, then **Notifications** (opening the page marks unread alerts and warnings read; filter by level) then **Tasks** (filter by domain, kind, status). Notification rows open `/notification/{id}` (title, level, message, related task and videos; opening marks an unread alert or warning read). Task rows open the task. Task history columns are Domain, Kind, When, Message. Error code and detail JSON stay on the task page.

**Reuse first.** Compose from `internal/web/templates/` and `internal/web/partials/`. Repeated chrome becomes a shared partial.

## Patterns

- **Chrome.** One treatment per role. Primary is the main commit (Save, Add, verify-import). Secondary is a second add beside a primary add. Outline is a labeled page-navbar action. A plain button is an icon-only action that is not destructive, and modal Cancel / Keep. Soft error is a delete trigger; the confirm submit is solid error. A settings-list delete that is not joined to Edit is a ghost button with error text. Muted is for empty or inherited values and for disabled label text. Mute the text, not a tooltip or anything that wraps one (opacity fades the tip). daisyUI already fades a disabled checkbox; do not fade it again. Warning means paused or recoverable, error means failed or blocked, success means healthy or complete. An active list filter uses the primary field color. A disabled control does not receive hover, so put the tip on a wrapper (inside a join, `aria-disabled` on the button instead, so the seam stays one control). Tailwind class names must appear whole in templates so `make css` can see them. An icon-only control has a tooltip. A labeled button does not repeat its label in a tip.
- **Import page.** Scan and import stay available; Match can create a series. On Import, **Mark new videos as ignored** is checked and disabled. Page help says to index with that on before matching files. File matching is a collapse under the header (series-folder `tvshow.nfo` lock, id / title / series / sidecar basename). Scan folder is a bordered fieldset with a joined Rescan. The shell paints immediately, then the match catalog and one folder scan run in parallel unless an `import` or `import_plan` task is already queued or running. Leaving the page drops those fetches with no error toast. While any of those tasks is open, the candidate list is a spinner plus a link to Tasks, and Scan folder, Rescan, and bulk Import stay disabled until the queue drains (live; **Import now** shows the busy shell at once; the last import auto-rescans). Scanning while imports are open returns a conflict. The file list waits on the scan; Match waits on the catalog. Long scans are not cut off by the usual request timeout. Candidates are a vertical list, one item per stem group (case-insensitive; `[id]` stripped so sidecars still merge), plus sidecar-only attach groups and other non-importable files. Media under a `tvshow.nfo` tree nests in one series-folder row (`tvshow.nfo` path plus series art; those meta files are not separate candidates). Each importable row: files and match note on the left, status and Match or Unmatch on the right. Unmatch clears the pick. No series or video summary text on the row. The path is primary, with a role icon; extra sidecars are a count plus icons (basename tips). Auto-match text does not include the remote id. An empty scan is an alert. No scan status line and no incomplete-full-scan warning on this page. A divider sits above the toolbar: **Auto-match** and **Reset matches** (quiet, no button chrome; Auto-match stays off after a scan, library switch, or Auto-match until someone matches, unmatches, bulk-picks a series, or resets; Reset clears every pick), **Match all to series** (series-only Match, applied to every importable item that still has no series), **Show only unmatched**, and **Import** on the right (wraps when tight; label `Import (matched/total)` for media; no animation). Changing the folder scans it, including once on load. **Rescan** scans again and keeps current matches. Folder change, Rescan, and Auto-match toast how many auto matches were found; the first load stays quiet. Match is a tall modal (series-only pick is the narrower one) with search, a poster series list, and a thumb video list, less detail than the main library. Locking a series leaves one row with a clear control. Picking a video, or finishing Add video, applies and closes. Tree-locked series cannot change in Match; unknown `tvshow.nfo` drafts are create-only (no catalog Match). **Create new series** is always on the series list and uses the shared Add series modal. **Create new video** is at the top of the video list, disabled until a series is locked, and opens the shared Add video modal (Import only for now). Fetch URL is the primary path (draft, then create with that draft). Manual entry is title and upload date only. A site or file id from `info.json` or `[id]` is sent when present; otherwise the server assigns `videos.id`. A new row is **ignored**. Success applies the real video id and closes. A series-only suggestion leaves the video empty. Search stays off while a video pick is locked for change. **Allow matching existing media** is only on media match. Off: packed media is omitted. Sidecar attach hides create actions and only lists videos that already have packed media. On: packed media is included and marked, and import replaces that media. One indexed video can be claimed by only one media item. **Import** opens a summary. With unknown `tvshow.nfo` folders, steps are **Series** then **Videos**: step 1 lists locked titles plus one shared delivery / monitored / root / quality form; step 2 is the video tree; final confirm is `POST /api/import/confirm` → `import_plan`. Without unknown series, a single-step summary queues via N× `POST /api/import/manual`. It warns when media will be replaced. Footer: Cancel, optional Back/Next, primary **Import now**. Post-import integrity follows each series quality profile **File integrity** (no summary checkbox). An orphan `info.json` is listed only. A lone `.nfo` or thumb is listed only; beside a same-name video it is metadata or art. Applying an orphan or sibling updates editable metadata, then regenerates the episode NFO from the database.
- **List / Add.** Existing rows are a table (`partials/list.html`). Add is a button that opens a modal. Edit is a per-row modal.
- **Source detail.** **Settings** and **Status** sit side by side at equal height. Settings is what Edit changes: URL (fixed after create), name, and for feeds the scan schedule, full-scan limit, title filters, and discovered video status. Status is kind, tool, domain, last scanned, and last error. On the series source row, Scan, Full scan, and Edit are icon-only. On source detail, Scan, Full scan, Edit, and Retry keep labels. Delete there is icon-only. Both scan buttons stay visible and disabled while a scan is queued for that source.
- **Notifications and settings chrome.** Settings → Connect leads with **Notifications**: a fixed in-app channel plus optional Apprise rows. Add defaults to **All**. Event choices are Alert / Warning / Info and **All** is exclusive with specifics. The Apprise URL is joined to **Test** (not written to History). The in-app channel is History plus the bell. Then the yt-dlp card (path, version, last checked, update channel, **Update now**; the schedule lives on Scheduler and gates boot and cron only). **arguments** has **player_client**. **plugins** lists packages, including bundled **yt-dlp-ejs**, and **fetch_pot**. Settings → General **Authentication**: change username or password (no current password; length 4 to 72) and an API key row (copy, regenerate) with a link to the OpenAPI document. **External services** shows the FlareSolverr and PO token URLs as disabled fields with a health icon, filled in after the page shell. **fetch_pot** stays disabled until the PO URL is set. **Appearance** is the theme picker, this browser only. Inline settings forms save on change or blur. Modals keep Save. The stats header says chart samples are kept for one year. Setup and login have no app shell. The user menu includes **Log out**.
- **Tasks.** Two intro lines: queues are per domain, and pause does not stop interactive metadata prefetch. Each host lane title is the domain (warning when paused), then limit chips when the lane has open or scheduled work (same order as the Domain override form; rate in binary units; a host override is full strength and a default is muted), then queue status left of History: **Paused** (warning; busy slide and a tip while tasks still run; quiet label when nothing is open), **Cooldown** (fill counts down; do not flip to Idle at zero if rows are still active), **Idle** (empty; quiet label when nothing is open), **Active** (busy slide, free parallel slots), **Busy** (busy slide, max parallel reached). **Cancel all pending** sits just right of that status. The `system` lane is a title only. Open tasks are one list, running first, 10 per page, with a query key per lane so paging one host does not page the others. Scheduled `system` rows stay above that list. An empty lane has no empty-state alert. Pending progress is empty (warning while the lane is paused). Mid-run progress is determinate. A running task at 0%, 100%, or with no number is an indeterminate busy slide, updated in place so the animation does not restart. Task detail uses the same status and bar in the header. Download progress is per format, with throughput when yt-dlp reports it. Cookie fallback says when the attempt is without cookies, when it retries with cookies, and when cookies or a PO token were used, nested under that attempt. A re-encode cut and an integrity null-decode map time onto 0-1. Remux, pack, and copy-cut are a message only. A failed task shows the error code and cleaned yt-dlp error text. The notify label for `ytdlp_failed` is **yt-dlp failure**. A `rename_episodes` task lists renames (or a dry-run plan while still running). An integrity task shows ok / partial / skipped / failed, then failed videos only (capped).
- **Status badge.** Icon plus tooltip, same warning / error / success meaning as other status. History and task-detail chips use the shared partial. Live updates must keep using that partial.
- **Maintenance.** Settings → Maintenance: action checkboxes (Apply episode format, Regenerate all NFO files, File sync, Integrity check, Refresh sidecars; a busy system action shows queued and stays disabled), scope (whole library, series, or videos; clears after Run), **Preview renames** (only with Apply episode format; dry-run, cap 500), and **Run selected**. Confirm lists actions, scope, packed count, and warns when Refresh sidecars will contact source sites. File sync ignores scope and is also a Scheduler job. Integrity check and Refresh sidecars match the single-video actions, scoped. Checkboxes unlock when the system task finishes; the selection survives that refresh until Run.
- **Library picker.** Shared series/video modal for Import (one pick, create actions, allow-existing hint under the checkbox) and Maintenance (two columns, many series or many packed videos of one series, no create). With no series picked, Maintenance videos lists all packed media and picking one locks its series. Two or more series shows a hint instead of video checks. Bell and toasts stay above this modal.
- **Roots and quality profiles.** Table plus Add modal; rows edit and delete. Delete confirms when unused and is disabled with a used-by tip when assigned. An invalid root path keeps the modal open and marks Path. The profile list is alphabetical. The name tip is the format selector, one line.
- **UI labels in copy.** When hint, info, tooltip, flash, help, alert, or other operator-facing text names a page, nav item, button, control, setting, closed-set option, or status, wrap that exact label in ASCII single quotes (`'Import'`, `'Rescan'`, `'Mark new videos as ignored'`, `'Settings → Queue / Domains'`). One pair around a multi-word label. Do not use bold or backticks for those labels in UI strings. Ordinary English stays unquoted. This file may still use bold for layout. Quote exact operator wording.
- **Fields.** Shared field partials: the info tip sits by the label, not joined to the control. A join may add a non-editable prefix or suffix (episode format shows the series folder and extension). Invalid fields use the daisyUI validator; the hint is hidden until invalid. On a join, the validator wraps the join so the hint still lines up. A grouped section is a fieldset with a background and border. A disabled control keeps its value in a hidden input, puts the reason tip on a wrapper, and mutes the label and hint only. A disabled checkbox label says `(disabled)` and uses the same tip; there is no hint paragraph under it.
- **Scan schedule.** Shared cron join: field plus **enabled**. Off shows `never` and does not submit a schedule. Turning it back on restores this visit's value, else the field default. Scan defaults to `@weekly`. Free-form cron and the named presets stay available. The hint under a source schedule is about upload cadence, not the Scheduler page.
- **Empty values.** List cells use ASCII `-`, or a muted word such as never, none, or default. A detail row mutes the value only and uses those words, not `-`.
- **List filters.** One join: optional search, optional date, optional selects. No leading Filter label. A select or date submits on change; search submits on blur. Hide a select with fewer than two options (History keeps domain and kind even when empty). Series videos filter by source, year, then status. Years are distinct UTC upload years, plus Unknown. Series filters are root (hidden when only one), quality, delivery, and status. History notifications filter by level; history tasks by domain, kind, origin, and status. History pages are 20 rows. The history range is From / To plus a clear control that matches those fields. Live lists swap in place.
- **Filter bar.** Checkbox chips. Hide when fewer than two options. Empty means show all. New lists should use list filters instead.
- **List rows.** Optional select, media, title line (kind, warning, task), second line, optional progress, optional actions. Series rows use a circular poster and a headphones badge only for audio. Video placeholders use a play icon; packed media and a single-video source use a film icon. A feed uses a list icon, warning-colored when new videos are marked ignored.
- **Series list.** Page size 20. Status filter: monitored, unmonitored, complete, incomplete, has errors. Complete and incomplete use list progress: downloaded over downloaded plus open work (wanted, archive wait, download error, integrity failure). Incomplete includes those errors. Has errors is video errors and/or a source scan error. The bar is downloaded, then errors, then wanted; an unmonitored series uses a muted track. The label under the bar omits zero counts. The same bar sits on the series Videos header. The second line omits the root when only one exists, and shows quality as best for audio. A health badge appears only for a problem, in order: download error, integrity failure, source scan error, full scan incomplete with no schedule. Error badges include a count. Running tasks do not use this badge. Multi-select is sticky across filter swaps, hides row checkboxes until on, drops the title underline, and keeps the monitor control visible but disabled. The bar shows `N/M selected`, **Select all** when there is another page, and Edit, Edit metadata, and Delete, disabled until something is selected. A busy bulk edit locks the bar. Monitor is part of Edit, not a separate list action.
- **Source status.** One Status column: icon and a short label. Priority: running, pending, scan error, stalled or incomplete, then indexed or no schedule. Incomplete with a schedule is a warning and does not escalate to the series; the tip says the full scan is incomplete and when the next scan is. Incomplete with no schedule is an error and does escalate. Both tips mention regexp filters when title filters are set. A finished single says complete. A scheduled feed shows the last-scan summary; schedule off says disabled, with the last scan still in the tip. The tip can also mention a full-scan limit. The cell updates live. Source detail does not repeat this in the page subtitle; last scan and last error are on the Status card.
- **Scroll.** Full-page pager and filter links restore scroll on the same path. A POST that redirects back to the current path does too, including Tasks actions. Opt out when a navigation should start at the top. A panel that already live-swaps should keep doing that instead of a full page load.
- **Series videos.** Pager only below the list. Optional from/to query is still parsed; the join has no date fields. Multi-select matches the series list. Row Want, Ignore, Download now, and Delete stay visible but disabled while multi-select is on. The bar can refresh sidecars, edit metadata, and run icon-only Want, Ignore, Download now, and Delete. Each opens a confirm. Delete accepts downloaded and missing only; other statuses are skipped and the flash says so. Bulk metadata edit locks the bar while it runs. Scan, bulk edit, and file delete refresh the list.
- **Tooltips.** daisyUI tooltip only, never the native title. Do not put a tooltip on a flex row or a table cell; wrap a child. Keep an existing accessible name. Do not fade a tooltip host. List tables scroll with the page so a tip is not clipped. Inside a join, the tip stays on the joined control.
- **Video detail.** Media and details sit side by side, same idea as task Stages and Details. Media is the packed file with a poster when there is a thumb, or a still image plus audio for audio delivery, or empty. Known resolution, frame rate, container, and duration sit under the player. Details are status and metadata, no separate thumb row. Status shows the task indicator and, when a non-integrity task is open, a Queued or Running prefix and a link to the task. Otherwise an error status links out for details. The next row is file integrity: off (no media, or the profile has it off), eligible (profile on, no hash yet), hashed (hash, no schedule), monitored (hash and a schedule), or failed. An open integrity task, including a library check that covers this video, links beside the chip with the same Queued or Running prefix. The tip names the state and, when this media has been checked, when. The chip is this page only and does not live-update. History is a vertical timeline, newest first. Rows that share a task nest under that task, substages newest first. Discover and update projections stay their own nodes. Files are the media, then stem-matched companions (NFO, info.json, thumb, subs, SponsorBlock, other). Registered files open a preview; orphans do not. Subtitle, thumb, and other files can be deleted. Media, NFO, info.json, and SponsorBlock cannot.
- **Series files.** The series folder table lists `tvshow.nfo` and art when present. Names open a preview.
- **Metadata.** Series and video metadata share one library-wide suggestion list per field (studio, genres, tags, country, content rating, actor name, actor role). Content rating also seeds the US TV ratings. Genres, tags, and actors are ordered lists (index, move, remove) except where reorder is off (subtitle languages are chips). Creatorr-managed genre or tag rows have no remove or reorder. See [`download-and-library.md`](download-and-library.md). Subtitle language suggestions start with `all`, then common tags. Library metadata options for an automatic domain tag and for genres from categories default on and are not retroactive.
- **Source filters.** Feeds group full-scan limit and title include/exclude under **Filter**, with the line that only matching videos are indexed. **Discovered video status** is Wanted or Ignored. On Import, add-series locks that to Ignored. Singles do not show these fields.
- **Series settings.** Add, Edit, and bulk Edit share one field set: title (hidden in bulk), delivery, monitored, root, and quality profile. Bulk has a No-change option and pre-fills fields that agree. Edit locks title and root while a download, SponsorBlock cut, or initial integrity check for that series is open. Audio disables the quality profile and says audio uses the best available quality.
- **Metadata fetch.** The URL and Fetch are one join. Fetch fills the form only. Save writes the library. Cancel drops the draft. Video defaults to the source URL. The thumbnail slot appears once the video is packed. **Refresh sidecars** rewrites thumb, subtitles, and NFO from the source and never rewrites `info.json`. **Download now** is hidden when the video is already downloaded.
- **Modals.** Close only from Cancel or another explicit action, not from the backdrop. Cancel resets the form, restores art previews, and restores list chips. Closing without Cancel keeps what was typed. Clearing art hides the preview; a new file shows it again.
- **Flash.** Success, warning, and error are toasts under the navbar, not banners. They dismiss themselves and leave the URL. Field errors use the validator. Add series and Add video keep an in-modal alert only for errors that do not belong to a control. Success opens the new series, except Import match, which stays and locks that series.
