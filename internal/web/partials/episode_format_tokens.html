{{define "episode_format_tokens"}}
Available format tokens
Token Meaning
{id} site video id
{domain} source hostname
{series} / {series:N} series title for the stem or subfolders (optional); series folder itself is always {series:100}-equivalent. :N caps runes
{title} / {title:N} video title; :N caps runes
{pack-role} empty for regular episode; Specials for Special episode; special feature name (e.g. trailers) for features.
{episode} / {episode:04} 1-based index for regular episodes within the series UTC year (oldest upload first; equal times use arrival order; undated last by id). Special episode: among all Specials in the series. Special feature: among the same feature name series-wide. Bare form is unpadded; :04 zero-pads.
{date} release date (YYYY-MM-DD)
{year} calendar year (year-season for regulars, e.g. 2026). Optional cosmetic token for Special feature stems; does not change the extras folder.
{month} / {month:02} UTC release month; :02 zero-pads
{day} / {day:02} UTC release day; :02 zero-pads
{hour} / {hour:02} UTC release hour (0–23); :02 zero-pads
{minute} / {minute:02} UTC release minute (0–59); :02 zero-pads

Date tokens ({date}, {year}, {month}, {day}, {hour}, {minute}) need a known upload date. {episode} follows the pack-role bucket (regulars need a dated year; Specials and features still number undated videos by id).
