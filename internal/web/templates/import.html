File matching

Auto-match runs these criteria in order.

Series

  1. tvshow.nfo <uniqueid>
  2. tvshow.nfo <title>
  3. Folder name

Videos

  1. Remote ID: sibling .nfo <uniqueid>, then [id] in filename, then info.json id
  2. Title similarity on cleaned filename
  3. Series from parent folder / basename (series only; pick a video next)
Create the series first and add sources with 'Mark new videos as ignored' so auto-match can use the video index. Or drop a tvshow.nfo tree into the import folder to create series on confirm.
