File matching
  1. Series folder: tvshow.nfo in a directory locks every media file under that folder (and subfolders) to that series. The file list wraps those media under one row that shows tvshow.nfo and series art. Unknown shows create new videos only (no Match to catalog); Import summary step 1 picks shared delivery / monitored / root / quality. Series art beside the NFO is imported on confirm. Nested tvshow.nfo trees own their own subtree.
  2. Media auto-match.
    1. Remote ID: sibling .nfo <uniqueid>, then [id] in filename, then info.json id.
    2. Title similarity on cleaned filename basename.
    3. Series suggestion from parent folder / basename (series only; pick a video in the row dropdown).
  3. Sidecars: .nfo is first for editable episode metadata and identity (<uniqueid>); thumb needs a same-basename video beside it. Subs match by directory + basename to packed media. info.json is provenance (URL / tech); ID fallback only.
Create the series first and add sources with 'Mark new videos as ignored' so auto-match can use the video index. Or drop a tvshow.nfo tree into the import folder to create series on confirm.
