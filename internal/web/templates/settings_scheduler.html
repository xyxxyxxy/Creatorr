Scheduler

The scheduler queues recurring work such as downloading videos and scanning sources for new videos.

Scan schedule is set individually on each feed source, because it depends heavily on that source. Some creators upload often, others rarely. Use the longest interval that still feels comfortable so Creatorr does not make excessive site requests.
