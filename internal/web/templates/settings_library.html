Available format tokens
Token Meaning
{id} site video id
{domain} source hostname
{series} / {series:N} series title for the stem or subfolders (optional); series folder itself is always fixed. :N caps runes (bare is not truncated)
{title} / {title:N} video title; :N caps runes
{episode} / {episode:000000} MMDD + same-day index (00…; oldest upload first that UTC day). Equal times use arrival order. Default format uses :000000 so January is 01… (6 digits).
{date} release date (YYYY-MM-DD)
{year} calendar year (year-season, e.g. 2026)
{month} / {month:02} UTC release month; :02 zero-pads
{day} / {day:02} UTC release day; :02 zero-pads

The following tokens become available after the release date of a video is known: {date}, {year}, {month}, {day}, and {episode}.

Generate new stream URL token?

A new token invalidates every existing .strm file immediately.

After confirming, run Regenerate all .strm files under Maintenance on this page so library .strm files pick up the new token.

Regenerate all NFO files?

Queues a system-lane task that rewrites episode .nfo for every video with media on disk, and tvshow.nfo for series that already have a folder. Unchanged files are skipped. Safe to interrupt - resumes after Creatorr restart. Info.json and thumbnails are left unchanged.

Apply episode format?

Renames packed episode files to the current episode format (system lane). Can take a while. Other downloads and scans keep running. Videos with an active download or pack stream task will be skipped - run again later for those.

Regenerate all .strm files?

Queues a system-lane task that rewrites every on-disk .strm to the current External Creatorr URL and stream URL token. Unchanged files are skipped. Safe to interrupt - resumes after Creatorr restart. Does not re-resolve streams or touch NFO/thumb files.

Clear beginning of stream cache?

Queues a system-lane task that deletes all beginning caches under the download-beginnings cache directory and clears the beginning-cached flag on every video. Pending beginning-cache tasks are cancelled. Does not re-download beginnings; pack and file sync may refill them later when the setting is above zero.

Clear progressive stream cache?

Queues a system-lane task that deletes all progressive on-play caches under the playback-cache directory and clears progressive cache columns on every video. Beginning caches are left alone.
