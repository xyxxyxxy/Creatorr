Domain defaults

Per-hostname queue depth and concurrency. Overrides below replace these for individual domains.

Domain Queues
Max download tasks

Maximum number of download tasks to be queued for the given domain. 'Queue download' user action bypasses this limit.

Max parallel tasks

How many tasks may run at once on this domain. Cannot exceed 'Max download tasks'.

Task cooldown
seconds

Pause after a task starts before another may start within the queue (still applies when several run in parallel).

yt-dlp throttling
Download rate limit {{template "download_rate_limit_join" (dict "Value" .DefaultLimits.DownloadRateLimit "Required" true)}}

Maximum download rate (yt-dlp --limit-rate).

Sleep between requests
seconds

Seconds yt-dlp waits between HTTP requests (metadata, media fragments, and subtitles) to avoid rate limits. Same value for --sleep-requests, --sleep-subtitles, and --sleep-interval.
