Domain defaults

Per-hostname queue depth and concurrency. Overrides below replace these for individual domains.

Concurrency

Task cooldown
seconds

Pause after a task starts before another may start (still applies when several run in parallel).

Sleep between requests
seconds

Seconds yt-dlp waits between HTTP requests (metadata, media fragments, and subtitles) to avoid rate limits. Same value for --sleep-requests, --sleep-subtitles, and --sleep-interval. Does not apply to stream play.

Max download queue

Maximum number of download tasks to be queued for the given domain. 'Download now' user action bypasses this limit.

Max parallel tasks

How many tasks may run at once on this domain. Cannot exceed 'Max download queue'.

Download rate limit {{template "download_rate_limit_join" (dict "Value" .DefaultLimits.DownloadRateLimit "Required" true)}}

Maximum download rate (yt-dlp --limit-rate).

Stream play rate limit {{template "download_rate_limit_join" (dict "Name" "stream_play_rate_limit" "Value" .DefaultLimits.StreamPlayRateLimit "Required" true "HideG" true)}}

Separate streaming rate limit. Makes sure streams do not buffer because of the general 'Download rate limit'.
